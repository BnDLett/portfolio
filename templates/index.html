About This Website

This website is written and styled primary by HTML and CSS. There is no Javascript used throughout this entire website. "That doesn't show us your programming skills," yes, but technically no. In this modern programming world, many dynamic websites are written with Javascript. Javascript is extremely powerful for websites. However, it can also come at a cost: performance. Whenever I was 13, I had a fairly low performance computer. It wouldn't even run Linux at a decent speed. As such, I was also painfully aware of when a website wasn't properly optimized. The culprit? Too much Javascript. Whenever you're writing a static website like this, the usage of Javascript is unnecessary. All the variables (such as my age) is provided onto the page via the back-end.
